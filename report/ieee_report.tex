\begin{abstract}
Autonomous robotic systems operating in unconstrained human environments require the ability to select objects based on contextual affordances rather than raw categorical labels. Although contemporary object detectors identify and localize physical entities with high precision, they cannot determine an object's functional suitability for open-ended human tasks. This paper presents SCORE (Semantic and Confidence-Based Object Ranking at the Edge), an edge-deployable, training-free framework for task-aware object selection. SCORE integrates an anchor-free YOLOv8-nano detector with a dual-tier semantic reasoning architecture: an ultra-compact 35.5~KB INT8 offline affordance bank for standard objects, paired with an on-demand Large Language Model fallback via OpenRouter for open-vocabulary concepts and novel task commands. Semantic relevance is evaluated using cosine similarity over 384-dimensional Sentence-BERT embeddings and fused linearly with visual detection confidence (70/30 weighting). A dual-stage gating mechanism (similarity threshold 0.12, score threshold 0.25) reliably rejects candidate selections in negative scenes lacking actionable tools. Evaluated on the COCO-Tasks benchmark, SCORE achieves 36.2\% mAP on predicted detections and 76.8\% top-1 accuracy on ground-truth boxes---outperforming prior Gated Graph Neural Network baselines by 3.6\% while executing in 140--150~ms on commodity CPU hardware under 15~W power dissipation, completely eliminating workstation GPU dependency.
\end{abstract}

\section{Introduction}
Autonomous robotic systems operating alongside humans in domestic and industrial environments must interpret physical surroundings through the lens of human tasks rather than static category labels. While modern deep convolutional and vision-transformer architectures localize objects with remarkable precision, knowing that an entity belongs to the class ``chair'' or ``table'' provides insufficient information to determine whether that object can fulfill an immediate task request. For example, an elderly individual requesting an object to ``sit comfortably'' requires a compliant, upholstered sofa rather than a rigid bar stool. Similarly, an instruction to ``reach an elevated shelf'' necessitates a structurally rigid, load-bearing stepping surface; selecting a delicate decorative chair introduces severe fall hazards. Furthermore, in scenarios where the visual scene completely lacks an appropriate tool---such as an instruction to ``cut fruit'' inside an office devoid of cutting implements---a safe robotic agent must actively reject the request rather than hallucinating an arbitrary execution.

The foundational work on task-driven detection by Sawatzky et al. [1] introduced the COCO-Tasks benchmark using Gated Graph Neural Networks (GGNN). Despite its pioneer status, their architecture presents severe deployment bottlenecks: it requires end-to-end supervised training on approximately 30,000 task-annotated images, depends on a bulky ResNet-101 backbone ($>$44 million parameters), remains restricted to 14 predefined tasks, and requires power-intensive GPU hardware dissipating over 150~W.

To overcome these fundamental constraints, this paper introduces SCORE (Semantic and Confidence-Based Object Ranking at the Edge), an edge-deployable, zero-shot framework that completely removes the requirement for task-specific dataset training. The principal contributions of this work are as follows:
\begin{itemize}
    \item We propose a decoupled task-driven object selection pipeline that eliminates recurrent graph message passing, preventing classification noise from cascading across scene entities.
    \item We design a hierarchical dual-tier semantic knowledge engine: a cache-resident 35.5~KB INT8 precomputed affordance matrix enabling sub-millisecond ($<$0.5~ms) lookup for standard objects, coupled with dynamic OpenRouter LLM distillation for arbitrary open-vocabulary objects and verbs.
    \item We introduce an explicit dual-stage threshold gating filter (similarity threshold $\tau_{\text{sim}} = 0.12$, score threshold $\tau_{\text{score}} = 0.25$) that mathematically prevents false-positive actuations in negative scenes.
    \item We benchmark the architecture on the COCO-Tasks dataset and real-world edge hardware, demonstrating 36.2\% mAP at 140--150~ms latency on an unaccelerated CPU while consuming under 15~W power.
\end{itemize}

\subsection{Practical Deployment and Sustainability}
Robotic assistants deployed in home environments face strict constraints on electrical energy draw and thermal dissipation. By replacing workstation GPU clusters ($\sim$180~W) with low-power commodity CPUs ($<$15~W), the proposed system reduces operational energy consumption by over 90\%. This supports the United Nations Sustainable Development Goals (SDGs), notably Industry, Innovation, and Infrastructure (SDG 9, Target 9.5) through energy-efficient computing, Sustainable Cities and Communities (SDG 11, Target 11.7) by lowering deployment costs for assistive care robotics, and Decent Work and Economic Growth (SDG 8, Target 8.2) through automated warehouse object selection.

\section{Related Work}
Task-oriented perception spans visual affordance modeling, visual reasoning, and language-guided grounding.

Sawatzky et al. [1] pioneered the COCO-Tasks benchmark using recurrent message passing in Gated Graph Neural Networks [2]. While this captures inter-object relationships, graph updates tend to propagate misclassification noise across nodes, and retraining the network for novel tasks is computationally prohibitive. Parallel work in Visual Question Answering (VQA) [3, 4] showed the utility of fusing visual features with linguistic representations, which Anderson et al. [5] improved by replacing uniform CNN grids with object-level bounding box proposals.

Affordance learning has historically focused on dense pixel-level labeling or geometry. Nguyen et al. [6, 7] applied deep CNNs and conditional random fields to locate tool affordances. Chuang et al. [8] highlighted that functional utility changes dynamically with environment context, and Zhu et al. [9] modeled tool interactions through physical contact spaces. However, these methods rely on rigid task taxonomies and supervised annotations.

Vision-language models like CLIP [10] provide zero-shot transfer by projecting image patches and text into shared spaces, yet their computational footprint limits on-robot edge deployment. Sentence-BERT [11] addresses the text side efficiently, extracting 384-dimensional sentence embeddings on basic CPUs in roughly 15~ms. Coupled with parameter distillation concepts [12] and the semantic reasoning of recent language models [13], we show that lightweight object detectors [14] can be augmented with decoupled semantic vectors to achieve open-ended task selection without retraining.

\section{System Methodology and Architecture}

\begin{figure}[htbp]
\centering
\includegraphics[width=0.98\linewidth]{flowchart.png}

\label{fig:methodology}
\end{figure}

The overall operational architecture of SCORE is depicted in Fig.~\ref{fig:methodology}. The framework processes RGB imagery entirely on edge CPU hardware through four coordinated subsystems: perception front-end, hierarchical semantic retrieval, decoupled score fusion, and dual-stage relevance gating.

\subsection{Problem Formulation and Visual Perception}
Let an input frame be denoted by $\mathbf{I} \in \mathbb{R}^{H \times W \times 3}$ and a natural-language task prompt by $t \in \mathcal{T}$. The vision front-end utilizes an anchor-free Ultralytics YOLOv8-nano network ($\sim$3.2M parameters) to detect a set of candidate objects $\mathcal{O} = \{o_1, o_2, \dots, o_N\}$. Each candidate instance $o_i$ is characterized by the tuple:
\begin{equation}
    o_i = \big(b_i, c_i, \text{Conf}(o_i)\big)
    \label{eq:candidate}
\end{equation}
where $b_i = [x_1, y_1, x_2, y_2] \in \mathbb{R}^4$ designates spatial bounding box coordinates, $c_i \in \mathcal{C}$ is the predicted object category, and $\text{Conf}(o_i) \in [0, 1]$ represents visual detection confidence. Operating at $640 \times 640$ resolution, this stage executes in 110--120~ms per frame on a single commodity CPU thread.

\subsection{Hierarchical Dual-Tier Knowledge Representation}
To reconcile real-time edge latency with open-world generalization, semantic affordance reasoning is partitioned into two tiers:
\begin{itemize}
    \item \textbf{Tier 1 (Cache-Resident INT8 Knowledge Bank):} For standard household categories ($|\mathcal{C}| = 80$ COCO classes), physical affordances (e.g., support rigidity, thermal capacity, grasp compliance) are distilled offline into concise semantic descriptors and mapped into 384-dimensional dense vectors using a pre-trained Siamese Sentence-BERT network $\phi(\cdot)$ [11]. These representations are quantized to an INT8 matrix occupying merely 35.5~KB of storage. Upon object detection, the corresponding affordance embedding $\mathbf{e}_{o_i} \in \mathbb{R}^{384}$ is retrieved in $O(1)$ time ($<$0.5~ms) directly from CPU cache.
    \item \textbf{Tier 2 (Dynamic LLM Affordance Distillation):} When an untrained open-vocabulary object ($c_i \notin \mathcal{C}_{\text{COCO}}$) or a novel action verb appears, Tier~2 activates an on-demand fallback across an automated model chain (NVIDIA Nemotron, Google Gemma) via OpenRouter. The dynamic model extracts key physical properties required for the task. The distilled text is encoded by $\phi(\cdot)$ into a 384-d vector and stored locally in \texttt{openrouter\_cache.json}, ensuring that subsequent queries incur zero API latency.
\end{itemize}

\subsection{Decoupled Score Formulation and Dual-Gate Gating}
The semantic relevance $\text{Sim}(o_i, t)$ between candidate affordance $\mathbf{e}_{o_i}$ and task embedding $\mathbf{e}_t = \phi(t)$ is quantified via cosine similarity:
\begin{equation}
    \text{Sim}(o_i, t) = \frac{\mathbf{e}_{o_i} \cdot \mathbf{e}_t}{\|\mathbf{e}_{o_i}\|_2 \|\mathbf{e}_t\|_2}
    \label{eq:sim}
\end{equation}

To compute final candidate ranking, semantic suitability is linearly fused with visual detection confidence:
\begin{equation}
    \text{Score}(o_i) = \alpha \cdot \text{Sim}(o_i, t) + (1 - \alpha) \cdot \text{Conf}(o_i)
    \label{eq:score}
\end{equation}
where $\alpha \in [0, 1]$ controls the trade-off between functional utility and perceptual certainty. We set $\alpha = 0.70$ based on empirical tuning, guaranteeing that physical utility dominates selection while retaining detection confidence as a verification signal.

To prevent hazardous actuations in scenes devoid of task-appropriate tools (negative scenes), candidates are subjected to a dual-gate decision rule:
\begin{equation}
    \hat{o} = \begin{cases}
    \arg\max_{o_i \in \mathcal{O}} \text{Score}(o_i), & \text{if } \exists o_i \text{ s.t. } \text{Sim}(o_i, t) \ge \tau_{\text{sim}} \wedge \text{Score}(o_i) \ge \tau_{\text{score}} \\
    \emptyset, & \text{otherwise}
    \end{cases}
    \label{eq:gating}
\end{equation}
where $\tau_{\text{sim}} = 0.12$ and $\tau_{\text{score}} = 0.25$. If all candidates fail either threshold, the system returns $\emptyset$ with an explicit status \texttt{NO\_SUITABLE\_OBJECT\_FOUND}, safely aborting operation.

\textbf{Task Selection Accuracy:} On the COCO-Tasks benchmark, SCORE achieves 36.2\% mAP@0.5 on predicted detections and 76.8\% top-1 accuracy on ground-truth bounding boxes. This surpasses the supervised GGNN baseline by +3.6\% and +2.6\% respectively, despite SCORE requiring zero task-annotated training images. Decoupling visual candidate isolation from semantic affordance scoring prevents localized classification noise from corrupting global scene context.

\textbf{Inference Latency and Real-Time Execution:} By replacing iterative message-passing convolutions with cache-resident vector lookups, end-to-end pipeline latency drops from $\sim$450~ms on a discrete workstation GPU to 140--150~ms on a standard commodity CPU thread, delivering a $3\times$ acceleration on lightweight hardware.

\textbf{Power Dissipation and Edge Feasibility:} Executing entirely on commodity CPU architectures eliminates dedicated accelerator hardware, reducing active power dissipation from $\sim$180~W to under 15~W (a 92.2\% power reduction). This energy profile is vital for battery-constrained mobile assistive platforms.

\section{Ablation Study and Architectural Analysis}
We analyze the core design decisions that govern SCORE's efficiency, robustness, and runtime characteristics.

\subsection{Sensitivity Analysis of Fusion Parameter $\alpha$}
The weight parameter $\alpha$ in \eqref{eq:score} balances semantic suitability against perceptual certainty. Relying exclusively on semantic similarity ($\alpha = 1.0$) exposes the robot to false detections; an image artifact misclassified as a ``towel'' with marginal confidence (e.g., 0.10) would erroneously be selected for a cleaning task. Weighting detection confidence by $1 - \alpha$ enforces physical verification. Conversely, setting $\alpha = 0.70$ guarantees that functional suitability dominates over visual salience (e.g., selecting a compliant sofa over a high-confidence rigid table for resting).

\subsection{Memory Hierarchy and Inference Latency Trade-Offs}
Querying cloud-hosted LLMs synchronously on every video frame introduces 800--1500~ms latency and creates fragile network dependencies. Pre-quantizing affordance vectors for standard categories into an INT8 matrix guarantees deterministic, cache-resident execution ($<$0.5~ms) on low-power edge CPUs. The dynamic LLM tier acts strictly as an asynchronous fallback for novel terms, persisting distilled descriptors to a local cache to eliminate recurring overhead.

\subsection{Error Cascading in Graph Neural Networks vs. Decoupled Embeddings}
In baseline Gated Graph Neural Networks [1], object nodes iteratively exchange messages across recurrent propagation steps. A classification error or false detection on a single node corrupts feature representations across all adjacent graph nodes. In contrast, SCORE evaluates candidates independently in a metric semantic space. This decoupled formulation guarantees bounded error propagation, prevents cascading failure, and removes workstation GPU dependencies.

\section{Conclusion}
This paper presented SCORE, an edge-deployable, zero-shot framework for task-aware object selection in assistive robotics. By decoupling visual perception from semantic affordance reasoning, SCORE achieves 36.2\% mAP on the COCO-Tasks benchmark---surpassing prior supervised Gated Graph Neural Networks by 3.6\%---while executing in 140--150~ms on commodity CPU hardware with sub-15~W power dissipation. The dual-tier knowledge architecture balances deterministic sub-millisecond local inference with dynamic open-vocabulary LLM reasoning. Future work will investigate end-to-end integration with 6-DOF grasp pose generation and multi-room 3D semantic SLAM.
